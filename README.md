## 🚀 Проекты

### 📚 [eLIBRARY Collector](https://github.com/IVGrishina/elibrary-source-collector) — флагман

Flask-приложение, превращающее сохранённые страницы поиска **eLIBRARY.RU** в структурированную базу источников.

| Возможность | Что это даёт исследователю |
|---|---|
| Парсер 1000/1000 записей | Массовый перенос подборки в Excel/CSV за секунды |
| Карточки-источники с цитированиями | Сортировка «как в подборке / по цитируемости / по году» |
| Дайджест аннотаций | Обзор литературы по всему корпусу — с точными ссылками |
| Полный цикл «источники → обзор» | От сохранённой страницы поиска до готового обзора |

Весь проект собран в паре с Claude Code — от первой страницы до скиллов для субагентов. *Литературный обзор по собранной подборке в этом проекте писала не я — его написал субагент по собственному дайджесту аннотаций.*

## 🚀 Projects

### 📚 [eLIBRARY Collector](https://github.com/IVGrishina/elibrary-source-collector) — flagship

A Flask application that turns saved **eLIBRARY.RU** search-result pages into a structured source database.

| Feature | What it gives the researcher |
|---|---|
| Parser: 1000/1000 records | Bulk transfer of a collection into Excel/CSV in seconds |
| Source cards with citation counts | Sorting "as in the collection / by citations / by year" |
| Annotation digest | A literature overview across the whole corpus — with precise references |
| Full "sources → review" cycle | From a saved search page to a finished review |

The entire project was built in tandem with Claude Code — from the first page to the subagent skills. *The literature review for the collected corpus was not written by me — a subagent wrote it from its own annotation digest.*
